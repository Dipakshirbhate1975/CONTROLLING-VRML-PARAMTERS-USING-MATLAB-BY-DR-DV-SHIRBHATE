VRML is a nonproprietary language used for scientific simulation and visualization. VRML have the capability of holding dynamic numerical values in the matrices for its interactive objects. These matrices hold the values for manipulation like rotation, scaling, transparency, color, translation etc. Using Simulink’s MATLAB interface, these numeric values can be dynamically varied which in turn will allow the user to exercise control over VRML object. The Simulink Graphic User Interface (GUI) presented in this paper demonstrate dynamic simulation of interactive Virtual Table/Desk Lamp using MATLAB’s Simulink Interface along with Electronic Hardware circuitry.  This paper describes how interactive VRML object can be controlled using MATLAB’s Simulink interface. The MATLAB’s Simulink capabilities can be utilized for real time simulation of interactive Table/Desk Lamp in virtual Environment.The concept can be applied for variety of applications involving similar requirements. The concept presented in this paper can be extended for full fledge complex simulator design.
